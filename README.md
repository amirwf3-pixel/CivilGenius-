## 🎯 ویژگی‌های کلیدی پلتفرم

- 🏗️ **طراحی فونداسیون گسترده:** محاسبه ظرفیت باربری ترزاقی، کنترل برش پانچ ACI و متره کامل.
- 📏 **طراحی تیر بتن آرمه:** طراحی خمشی/برشی، خاموت‌گذاری + **رسم زنده دیاگرام لنگر و برش (Plotly)**.
- 🏛️ **طراحی ستون بتنی:** کنترل بار محوری + **رسم زنده منحنی اندرکنش P-M (P-M Diagram)**.
- 🤖 **دستیار هوشمند آیین‌نامه:** چت‌بات تخصصی مسلط بر مقررات ملی ساختمان ایران با هوش مصنوعی Llama 3.3.
- 📊 **دفترچه محاسبات Excel:** خروجی اتوماتیک چندبرگی، فرمول‌نویسی زنده، تم شرکتی بدون خطوط شطرنجی.
- 📄 **گزارش فنی Word:** تولید گزارش جامع با جلد گرافیکی سرمه‌ای/طلایی، جداول رنگی و راست‌چین مطلق.
- 📐 **نقشه اجرایی AutoCAD:** ترسیم خودکار فایل DXF شامل پلان، مقطع عرضی میلگردها و متون فارسی خوانا.

---

## 🛠️ تکنولوژی‌های به‌کار رفته (Tech Stack)

- **Language:** Python
- **Frontend / UI:** Streamlit (Mobile Responsive), Custom CSS
- **AI / LLM:** Groq API (Llama-3.3-70b-versatile)
- **Data Visualization:** Plotly Graph Objects
- **CAD Automation:** ezdxf, arabic-reshaper, python-bidi
- **Office Automation:** openpyxl, python-docx
